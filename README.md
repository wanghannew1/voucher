# 进账明细生成器 Demo

> **注意**：本项目仅包含源代码，所有财务敏感数据（银行流水、发票信息、客户编码等）需保存在本地，**禁止上传至任何远程仓库**。

## 项目简介

这是一个 Python 演示程序，用于根据银行对账单和开票信息，自动生成进账（收款）的财务凭证明细。

### 核心功能

| 功能 | 说明 |
|------|------|
| 银行流水解析 | 自动识别吉林银行、工商银行、建设银行三家银行的不同 Excel 格式 |
| 发票备注解析 | 从发票备注中提取「扣除额（工资）」和「管理费（收入）」 |
| 智能匹配 | 按客户名称 + 金额 + 日期，将银行进账与发票自动匹配 |
| 凭证生成 | 自动生成标准凭证分录：借 1002 / 贷 224101 / 贷 222121 / 贷 600101 |
| 图形界面 | tkinter 界面，支持文件选择、匹配预览、凭证展示、Excel 导出 |
| 命令行模式 | 无需 GUI 环境，直接运行演示完整流程 |

## 快速开始

```bash

git clone git@github.com:wanghannew1/voucher.git
cd voucher

# 创建虚拟环境
python3 -m venv venv

# 安装依赖
```

### 2. 准备本地数据（自行放置，不上传）

将以下财务数据文件放置在本地对应目录中：

| 数据类型 | 文件路径 | 说明 |
|---------|---------|------|
| 银行对账单 | `银行流水/*.xlsx` 或 `*.xls` | 吉林银行、工行、建行 |
| 发票信息 | `发票信息/*.xlsx` | 含「扣除额」「管理费」备注 |
| 客户编码 | `代码资料/客户编码.xlsx` | 客户名称↔编码映射 |
| 科目代码 | `代码资料/科目代码.xlsx` | 现金流量科目代码 |

> **安全提醒**：以上文件已加入 `.gitignore`，`git add` 时不会进入暂存区。

## 凭证分录规则

### 匹配到发票的凭证（4条分录）

以「长春海关技术中心」一笔进账为例：

| 科目编码 | 科目名称 | 方向 | 金额 | 辅助核算 |
|---------|---------|------|------|----------|
| 1002 | 银行存款 | 借 | 114,087.63 | 银行档案 |
| 224101 | 其他应付款-客户往来 | 贷 | 112,567.63 | 客户档案 |
| 222121 | 应交税费-简易计税 | 贷 | 86.04 | — |
| 600101 | 派遣收入 | 贷 | 1,433.96 | 部门 + 项目档案 |

**数据来源**：发票备注 `扣除额:112567.63 管理费：1520`
- 扣除额 → 贷 224101（工资部分，不计税）
- 管理费 − 税额 → 贷 600101（收入净额）
- 税额 → 贷 222121

### 未匹配到发票的凭证（2条分录）

| 科目编码 | 科目名称 | 方向 | 金额 | 辅助核算 |
|---------|---------|------|------|----------|
| 1002 | 银行存款 | 借 | 金额 | 银行档案 |
| 224101 | 其他应付款-客户往来 | 贷 | 金额 | 客户档案（如有） |

## 匹配逻辑

系统按以下优先级自动匹配银行进账与发票：

1. **名称 + 金额 + 日期**（精确匹配，得分 1.0）
2. **名称 + 金额**（得分 0.9）
3. **名称 + 日期**（得分 0.7）
4. **金额 + 日期**（得分 0.6）
5. 仅名称 / 仅金额（得分 0.4–0.5）

名称匹配支持：精确匹配 → 子串包含 → 去后缀（去掉"有限公司"等）。
