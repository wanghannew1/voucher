# 进账明细生成器 Demo

> **注意**：本项目仅包含源代码，所有财务敏感数据（银行流水、发票信息、客户编码等）需保存在本地，**禁止上传至任何远程仓库**。

## 项目简介

这是一个 Python 演示程序，用于根据银行对账单和开票信息，自动生成进账（收款）的财务凭证明细。

### 核心功能

| 功能 | 说明 |
|------|------|
| 银行流水解析 | 自动识别吉林银行、工商银行、建设银行三家银行的不同 Excel 格式 |
| 发票备注解析 | 从发票备注中提取「扣除额（工资）」和「管理费（收入）」 |
| 智能匹配 | 按客户名称 + 金额 + 日期，将银行进账与发票自动匹配 |
| 凭证生成 | 自动生成标准凭证分录：借 1002 / 贷 224101 / 贷 222121 / 贷 600101 |
| Web 界面 | Streamlit 界面，支持文件上传、匹配预览、凭证展示、Excel 下载 |
| 命令行模式 | 无需 GUI 环境，直接运行演示完整流程 |

## 快速开始

### 1. 环境准备

```bash
# 克隆仓库（仅代码，无数据）
git clone git@github.com:wanghannew1/voucher.git
cd voucher

# 使用 uv 创建虚拟环境（推荐）
uv venv --python 3.14
source .venv/bin/activate

# 安装依赖
uv pip install -r demo_income/requirements.txt
```

> 也可使用传统方式：`python3 -m venv .venv && .venv/bin/pip install -r demo_income/requirements.txt`

### 2. 运行方式

#### 方式一：Web 界面（推荐）

```bash
streamlit run demo_income/main.py
```

浏览器自动打开 `http://localhost:8501`，功能：
- 左侧边栏上传银行对账单和发票文件
- 点击「加载数据」→「自动匹配」→「生成凭证」
- 主区域查看进账流水、匹配结果、凭证分录
- 支持一键导出 Excel

#### 方式二：命令行演示

```bash
python demo_income/demo_cli.py
```

输出示例：

## 凭证分录规则

### 匹配到发票的凭证（4条分录）

| 科目编码 | 科目名称 | 方向 | 金额 | 辅助核算 |
|---------|---------|------|------|----------|
| 1002 | 银行存款 | 借 | 价税合计 | 银行档案 |
| 224101 | 其他应付款-客户往来 | 贷 | 扣除额 | 客户档案 |
| 222121 | 应交税费-简易计税 | 贷 | 税额 | — |
| 600101 | 派遣收入 | 贷 | 管理费−税额 | 部门 + 项目档案 |

### 未匹配到发票的凭证（2条分录）

| 科目编码 | 科目名称 | 方向 | 金额 | 辅助核算 |
|---------|---------|------|------|----------|
| 1002 | 银行存款 | 借 | 进账金额 | 银行档案 |
| 224101 | 其他应付款-客户往来 | 贷 | 进账金额 | 客户档案（如有） |

## 匹配逻辑

系统按以下优先级自动匹配银行进账与发票：

1. **名称 + 金额 + 日期**（精确匹配，得分 1.0）
2. **名称 + 金额**（得分 0.9）
3. **名称 + 日期**（得分 0.7）
4. **金额 + 日期**（得分 0.6）
5. 仅名称 / 仅金额（得分 0.4–0.5）

名称匹配支持：精确匹配 → 子串包含 → 去后缀（去掉"有限公司"等）。
